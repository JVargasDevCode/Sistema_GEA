# 6. Tecnologias Utilizadas

Para o desenvolvimento do GEA — Gestão de Eventos Acadêmicos, serão utilizadas tecnologias voltadas ao desenvolvimento web, permitindo a construção da interface do sistema, implementação das regras de negócio e armazenamento das informações.

## 6.1 Visual Studio Code

O **Visual Studio Code (VS Code)** será utilizado como ambiente de desenvolvimento. Ele permitirá escrever, organizar e editar os códigos-fonte do projeto, além de disponibilizar recursos como extensões, integração com Git e ferramentas para diferentes linguagens de programação.

## 6.2 HTML5

O **HTML5** será utilizado na estruturação das páginas e componentes da aplicação web, definindo a organização dos elementos apresentados aos usuários.

## 6.3 CSS3

O **CSS3** será utilizado para definir a aparência e a organização visual da aplicação, incluindo layout, responsividade, fontes, espaçamentos e demais características visuais do sistema.

## 6.4 JavaScript

O **JavaScript** será utilizado para implementar comportamentos e funcionalidades da aplicação no ambiente web, permitindo a interação entre os usuários e o sistema.

## 6.5 React

O **React** será utilizado no desenvolvimento do frontend da aplicação. A tecnologia permitirá a criação de uma interface organizada em componentes reutilizáveis e facilitará a construção das diferentes telas do GEA.

## 6.6 Java

A linguagem **Java** será utilizada no desenvolvimento do backend e na implementação das regras de negócio do sistema. Será responsável pelo processamento das informações, gerenciamento das funcionalidades e comunicação com o banco de dados.

## 6.7 Python

A linguagem **Python** também fará parte do projeto, sendo utilizada conforme as necessidades definidas pela equipe durante o desenvolvimento. Sua utilização poderá auxiliar na implementação de funcionalidades específicas e no processamento de dados.

## 6.8 PostgreSQL

O **PostgreSQL** será utilizado como Sistema Gerenciador de Banco de Dados (SGBD) do projeto. Ele será responsável pelo armazenamento e gerenciamento das informações do GEA, como usuários, eventos, atividades, palestrantes, inscrições, presenças, avaliações e certificados.

## 6.9 SQL

A linguagem **SQL (Structured Query Language)** será utilizada para realizar operações no banco de dados PostgreSQL. Por meio do SQL será possível criar e estruturar as tabelas, inserir, consultar, alterar e excluir dados, além de estabelecer relacionamentos entre as diferentes informações armazenadas pelo sistema.
